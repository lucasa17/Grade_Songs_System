# 🎵 Grade Songs System

O **Grade Songs System** é uma aplicação desktop desenvolvida em **Java (Swing)** com **MySQL** que permite gerenciar coleções de álbuns e músicas, possibilitando ao usuário dar notas para cada música e organizar suas preferências musicais de forma simples e intuitiva.

---

## 🚀 Funcionalidades Principais

- 🧍‍♂️ **Autenticação de Usuário**
  - Login e cadastro de novos usuários.
  - Recuperação de senha via pergunta de segurança.

- 💿 **Gerenciamento de Coleções**
  - Criação, edição e exclusão de coleções musicais personalizadas.

- 🎶 **Gerenciamento de Álbuns e Músicas**
  - Cadastro de álbuns com informações do artista.
  - Adição e avaliação de músicas (com notas atribuídas pelo usuário).

- ⭐ **Sistema de Avaliação**
  - Ordenação de músicas por notas (crescente ou decrescente).
  - Visualização fácil das músicas mais bem avaliadas.
 
## 🧩 Tecnologias Utilizadas

- **Java 17+**
- **Swing (Interface Gráfica)**
- **MySQL (Banco de Dados)**
- **JDBC** para comunicação com o banco
- **MVC Pattern** para organização do código
